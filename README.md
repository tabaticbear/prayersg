# Pray for Singapore

A visual prayer map of Singapore. Each "lens" (schools, regions, economy, the nations) is shown as dots or shapes on a map. You tap one, learn about it, and pray for it.

**Lens 1: Schools.** Every MOE primary, secondary and mixed-level school (JCs too, as an optional filter) appears as a dot on the OneMap basemap. Tap a school to see:

- what it is known for: its Applied Learning (ALP) and Learning for Life (LLP) programmes, SAP/IP/GEP status, CCAs and MOE programmes
- links to its website, its MOE SchoolFinder page and directions
- a verse and prayer points written for that school, naming its principal and vice-principals, its level (PSLE or national exams), its gifts and its neighbourhood
- **Amen**, which marks the school as prayed (the dot gets a gold ring) and moves you to the next school

Use **Pray through these schools** to work through a filtered set, for example "Secondary schools in the East region". Your progress is saved in your browser.

## Running it

It's a static site with no build step.

```bash
python3 -m http.server 8000   # then open http://localhost:8000
```

To host it, turn on **GitHub Pages** (Settings → Pages → deploy from this branch, `/` root).

## School data

`data/schools.json` is generated by `scripts/build-schools.mjs`, which:

1. downloads MOE's *General information of schools* from data.gov.sg
2. adds CCAs, MOE programmes and distinctive programmes from the same MOE collection, when available
3. geocodes each postal code with OneMap's search API (results are cached in `data/geocode-cache.json`)

The **Update school data** GitHub Action runs this monthly, whenever the script changes, or on demand from the Actions tab. It commits the refreshed data. You can also run it locally (Node 18+):

```bash
node scripts/build-schools.mjs
```

If data.gov.sg rate-limits the job, add a free API key as the repository secret `DATA_GOV_SG_API_KEY`.

## Roadmap

| Phase | Lens | What you'd see |
|---|---|---|
| 1 ✅ | **Schools** | MOE primary/secondary schools, prayer points per school, a pray-through mode, progress |
| 1.5 | Schools+ | Pray by planning area ("all schools in Tampines"), daily school-of-the-day, share a school link (already works via `#school=`), notes/journal per school |
| 2 | **Regions & areas** | URA planning-area boundaries shaded by how much you've prayed; per-area facts (population, age, housing) from SingStat |
| 3 | **Institutions** | Hospitals, universities/polytechnics/ITE, government ministries, places of worship |
| 4 | **Economy** | Major sectors, CBD, ports/Jurong Island; flows of trade and money |
| 5 | **The nations** | World map: Singapore's links to other nations (trade, migrant workers, diaspora), unreached people groups |

Each lens will be a module that takes a dataset and supplies prayer points, so they all share the same map, detail panel and progress tracking.
